description: The Agent tool plane for turning existing OpenAPI services into secure, discoverable capabilities.

**Every API, Agent-ready.**

Realmroot turns existing OpenAPI services into secure, discoverable tools for
Agents. Resource teams keep the APIs, contracts, and enforcement they already
operate; they do not need to build and maintain a separate Agent integration.

The outcome is a complete operating path: an Agent finds the right tool,
receives the exact delegated authority it needs, and calls the original service
directly.

## One product, two layers

### Agent Tool Plane

- Register existing API resources and their live OpenAPI contracts
- Discover available resources and operations at task time
- Invoke any registered resource through the Realmroot Skill and Restish
- Expand Agent capability as new resources join, without new Agent-specific backend code

### Identity and Trust Infrastructure

Identity is the foundation, not the final outcome. Realmroot provides the
stable Agent identity, controller relationship, grant approval, token
coordination, revocation, and audit needed to make tool use safe.

The same realm also includes hosted authentication, OIDC, account management,
and administration for people and applications.

Tools without trust are unsafe. Identity without tools does not complete a
task. Realmroot brings both layers together:

> **Discover broadly. Authorize precisely. Call directly.**

## The responsibility boundary

Realmroot owns registration and discovery, Agent identity, delegated grant
lifecycle, and short-lived token coordination. It is not an HTTP proxy and
does not copy business permissions.

The resource server remains the final authorization boundary. It owns its API,
OpenAPI contract, scope semantics, object-level permissions, data, business
rules, and the final allow-or-deny decision.
